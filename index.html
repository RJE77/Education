02 / Deployment project

PXE boot to physical imaging

The deployment exercise began with WDS on DC01 and progressed from a virtual PXE client to a bootable WinPE USB for an isolated physical laptop.

Network boot

WDS and Windows PE

Installed WDS integrated with Active Directory, added an x64 Windows PE boot image from the ADK, and booted PXE-Test through UEFI into the WinPE command prompt. Confirmed a DHCP lease and successful ping to DC01.

Virtual deployment

Windows 11 image

Applied Windows 11 Pro from an install.wim share to a GPT disk, built UEFI boot files, configured Recovery, and reached Windows setup in PXE-Test.

Portable media

Two-partition USB

Created a 2 GB FAT32 WinPE boot partition and an NTFS image partition for the image file larger than FAT32's 4 GB file limit. Booted a physical laptop from the USB into WinPE.

Physical deployment

Image applied to the laptop

Identified the internal Kingston drive separately from the ONN USB, prepared EFI, Microsoft Reserved, Windows, and Recovery partitions, applied the Windows 11 Pro image, created UEFI boot files, and registered Windows Recovery. First boot verification is the remaining check.

03 / Troubleshooting notes

Problems traced to their cause

  1. Ubuntu received IPv6 but no IPv4 lease

    Checked its VirtualBox network attachment and moved the client onto the same internal network as the OPNsense LAN. It later received 192.168.50.106.

  2. PXE-Test showed a black screen with UEFI

    Changed the virtual machine to one vCPU. It subsequently displayed Windows Boot Manager, loaded WinPE, and reached the command prompt.

  3. WinPE could not use the physical USB as one FAT32 volume

    Separated boot files and the larger Windows image into FAT32 and NTFS partitions, then verified the image was visible from WinPE on the laptop.
